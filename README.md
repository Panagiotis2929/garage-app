## Περιγραφή
Εφαρμογή για τη μηχανοργάνωση ενός συνεργείου αυτοκινήτων: καρτέλες πελατών και οχημάτων, ιστορικό επισκέψεων και χιλιομέτρων, δελτία εργασίας με υπολογισμό κόστους (ΦΠΑ 24%), κατάλογος ανταλλακτικών με import από CSV, αναζήτηση, εκτύπωση PDF και αποστολή δελτίου με e-mail.

Χρήστες: ιδιοκτήτης, υπάλληλος υποδοχής, μηχανικός.

## Τεχνολογίες
Python 3.11+, PySide6, SQLite, reportlab

## Εγκατάσταση και εκτέλεση
```
pip install -r requirements.txt
python src/main.py
```
